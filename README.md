# Sistema Integral de Gestión de Restaurante (SIGR)

## Descripción
Aplicación web para gestionar pedidos, reservas, administración de menús, control de caja y generación de reportes.

## Requisitos
- Node.js v16+
- MySQL 8.0+

## Instalación
1. Clonar el repositorio: `git clone https://github.com/diegoyiasss/sigr.git`
2. Instalar dependencias: `npm install`
3. Ejecutar el servidor: `npm start`
